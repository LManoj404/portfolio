# Certificates — upload folder

Put your certificate images here as PNG or JPG.

Expected filenames (edit `src/data/gallery.js` if you prefer other names):

  oracle-generative-ai.png
  nasscom-data-science.png
  ibm-exploratory-data-analysis.png

Rules:
- Any file may be missing — the site shows an elegant
  "CERTIFICATE / IMAGE COMING SOON" placeholder instead.
- Missing files never cause broken images or build errors.
- Recommended size: 1200 x 900 (or any 4:3), under ~500 KB.
- Use only your own certificates. Do not commit anyone else's.
